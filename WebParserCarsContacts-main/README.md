# Driver Contacts Hub — robota.ua Public Contacts

Next.js вебзастосунок для Vercel, який шукає публічні вакансії robota.ua через серверний `/api/search`, витягує доступні контактні дані роботодавців, прибирає дублікати та зберігає результат у `localStorage` браузера.

## Що змінило в UI

- Додано адаптивний інтерфейс Driver Contacts Hub.
- Додано шаблони/категорії: водій, категорії B/C/CE, водій-експедитор, далекобійник, міжнародник, водій з власним авто, перевізник.
- Натискання категорії одразу запускає внутрішній пошук через `/api/search` — сторінка robota.ua автоматично не відкривається.
- Контакти показуються в таблиці цього самого застосунку.
- На мобільному таблиця автоматично перетворюється на картки.
- Збережено CSV/XLSX, локальне збереження, дедуплікацію, фільтр і службовий URL джерела.

## Локальний запуск

```powershell
npm install
npm run dev
```

Відкрити: `http://localhost:3000`

## Перевірка перед Vercel

```powershell
npm run build
```

Після успішної збірки проєкт можна розгортати на Vercel як звичайний Next.js проєкт.
